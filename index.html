Professional experience

5+ years of IT experience across software quality assurance, test automation, API validation and performance engineering in enterprise environments.

Wipro — Quality Engineering & Performance Testing

Senior SDET | Performance & Automation Engineer · 5+ years of IT experience
  • Quality assurance: Work across the testing lifecycle: understand requirements, design test scenarios and test cases, perform functional validation, integration checks, regression, smoke and sanity testing, and support defect retesting.
  • Test automation: Apply Selenium and programming/scripting experience in Java, Python, pytest and JavaScript to create repeatable checks, assertions, reusable test logic and maintainable test scripts.
  • API testing: Validate REST APIs with Postman, including request/response payloads, status codes, headers, parameters, bearer-token authentication, API keys, dynamic values and negative scenarios.
  • Performance engineering: Design and execute workload scripts using Apache JMeter and LoadRunner; support baseline, load, stress, spike, scalability and extended endurance testing.
  • Performance analysis: Analyse average, P95 and P99 response times, throughput, TPS, concurrency and error rates; assess workload behaviour and identify application, database and connection-pool bottlenecks.
  • Monitoring & troubleshooting: Correlate test execution with application and infrastructure telemetry using Splunk, Dynatrace, AppDynamics, Prometheus and Grafana.
  • Engineering collaboration: Partner with development, QA, database, infrastructure and DevOps teams on defect triage, root-cause investigation, test reporting and release-readiness discussions.
  • Delivery: Contribute to Agile ways of working, test evidence, technical documentation, Jira tracking and knowledge transfer.
